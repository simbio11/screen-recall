# 화면 기억 자동완성 (screen-recall)

앞 화면에서 본 글자를 까먹어서 되돌아가는 일을 없애는 Windows 프로그램입니다.
화면에 보였던 글자를 기억해 두었다가, 입력할 때 앞부분만 쳐도 추천해 줍니다.

```
이전 화면: "안녕하세요 홍길동 원장님"
지금 입력: 안ㄴ        → 추천창: [안녕하세요]
           Shift+Enter → "안녕하세요" 입력됨
```

## 실행

1. Python 3.10 이상 설치 (설치할 때 *Add python.exe to PATH* 체크)
2. `run.bat` 더블클릭 → 필요한 패키지를 설치하고 실행합니다.
3. 콘솔 창을 닫으면 종료됩니다.

## 단축키

| 키 | 동작 |
| :-- | :-- |
| Shift+Enter | 추천창이 **떠 있을 때만** 선택된 추천 입력. 추천창이 없으면 원래대로 줄바꿈 |
| Shift+↑ / Shift+↓ | 추천 선택 이동 |
| Esc | 추천창 닫기 (Esc는 앱에도 그대로 전달) |
| Ctrl+Alt+Shift+R | 일시정지 / 재개 |
| Ctrl+Alt+Shift+X | 기억 전부 지우기 |

## 동작 방식

| 부분 | 파일 | 하는 일 |
| :-- | :-- | :-- |
| 핵심 로직 | `recall_core.py` | 한글을 키 입력 단위 자모로 풀어 접두어 비교, 단어·짧은 구절로 쪼개 저장 |
| 수집 | `screen_recall.py` `collector` | 맨 앞 창의 글자를 Windows UI 접근성(UIA)으로 1.5초마다, 창이 바뀌면 즉시 읽음 |
| 감시 | `watcher` | 지금 입력 중인 칸의 커서 앞 글자를 0.12초마다 읽어 추천 계산 |
| 키 가로채기 | `hook_thread` | 저수준 키보드 훅. 추천창이 떠 있을 때만 Shift+Enter 등을 가로챔 |
| 입력 | `inserter` | 한글 조합 확정(→) → 친 글자만큼 지우기 → 추천 글자를 유니코드로 입력 |
| 추천창 | `Popup` | 커서 근처에 포커스를 뺏지 않는 작은 창 |

**한글 매칭:** "안ㄴ" → ㅇㅏㄴㄴ, "안녕하세요" → ㅇㅏㄴㄴㅕㅇ… 처럼 풀어서 비교하므로 조합 중인 글자도 맞습니다. 겹모음(ㅘ→ㅗㅏ)과 겹받침(ㄺ→ㄹㄱ)도 키 순서대로 풉니다.

## 개인정보

- 기억은 **메모리에만** 있고 디스크에 저장하지 않습니다. 프로그램을 끄면 사라지고, 3시간 지난 글자도 지워집니다.
- 비밀번호 칸, 지금 입력 중인 칸은 수집하지 않습니다.
- 비밀번호 관리자는 `EXCLUDE_PROCESSES`로 제외합니다. 더 뺄 프로그램이 있으면 `screen_recall.py` 위쪽 설정에 추가하세요.

## 알려진 한계 (실제 PC에서 확인 필요)

- 아직 실제 Windows에서 돌려보지 않았습니다. `recall_core.py`만 테스트(`python -m pytest tests`)를 통과했습니다.
- 접근성 정보를 내주지 않는 앱(일부 게임, 이미지 속 글자, 일부 전자차트 프로그램)의 글자는 못 읽습니다. 필요하면 OCR을 섞는 방식으로 확장합니다.
- 커서가 글 **중간**에 있을 때 한글 조합 중이면 확정 처리가 불안정할 수 있습니다.
- 관리자 권한으로 실행된 창에는 키 입력이 안 들어갑니다(이 프로그램도 관리자 권한으로 실행하면 해결).
- 휴대폰(안드로이드)은 별도 키보드 앱으로 만들어야 합니다 — 다음 단계 후보.
